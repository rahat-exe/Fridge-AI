# 🧊 Fridge-AI
> Tell us what's in your fridge. We'll tell you what to cook.

Fridge-AI is an AI-powered recipe finder that suggests personalized 
recipes based on your available ingredients and cuisine preferences — 
enriched with real instructions, ingredient lists, and YouTube tutorials 
via MealDB.

Built with Next.js, Better Auth, Groq AI, and TanStack Query.
